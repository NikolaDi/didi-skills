# 台架采集的判据

下列案例来自 DHO924S 固件 00.01.02。按当前仪器回读确定实际窗口。

| 现象 | Agent 应检查什么 |
| --- | --- |
| 单次结束显示 AUTO | 按顺序读取触发状态和扫掠模式。本机在 10 s/div、1 M 点、10 kSa/s 时约 51 s 后自然 STOP，再读到 AUTO。只有触发前后窗齐全、采样率及配置稳定、冻结帧一致时才接受。在等待或运行途中转 AUTO 要保留现场。 |
| 慢时基下 MODE 查询超时或出现 −232 | 200 ms/div 曾复现。普通捕获可分别读 XY、Auto ROLL 和实际时基；保留原始响应。 |
| `*OPC?` 返回 0 | 本机曾在错误队列为空时仍完整收到 CH1/NORM/WORD 1000 点，即 2000 字节负载。记录原始响应、状态、前导和长度，分别核对当前操作。MCP 返回的数组可能已抽稀，确认完整采样数用 `points`；二进制长度需要传输级证据。 |
| 两次数据一致，峰值仍可疑 | 查上下轨截幅、探头倍率、偏移、实际时间轴和事件是否在窗口内。NORM 是屏幕窗口；RAW 按实际存储深度、时间增量及触发位置解释。中途配置不符时在清理前保存前导原文和各项期望／实读值。 |
| CH1 近零或 CH4 电流明显摆动 | CH1 先查探头接触、DC 耦合、倍率与量程，再用已知非零直流对照。CH4 记录钳口方向和本体档位，10 mV/A 时 1 mV 对应 0.1 A。用闭合空钳测本底；面板和导出按同一 STOP 帧、同一通道与窗口比较。 |
