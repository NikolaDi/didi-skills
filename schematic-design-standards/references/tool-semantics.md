# 工具连接语义与验证边界

## 原生 EDA 与通用 SVG

| 对象 | 可检查内容 | 不应作出的推断 |
|---|---|---|
| 原生 EDA 工程 | 符号/引脚属性、网络作用域、端点、ERC 和可用的 PCB 一致性 | ERC 无错误不代表器件选型、稳定性或整机性能全部正确 |
| 通用 SVG 图例 | 记录的端点、引脚、标签、预期节点与实际几何路径，渲染后的图面可读性 | SVG 检查不是 EDA 原生 ERC，不绑定实际器件库、封装或制造数据 |
| 仅有电路图片 | 可辨的器件、标注、路径和图面关系 | 不能证明隐藏连接、真实网表、封装映射或 PCB 一致性 |

处理连接时先确定正在使用哪一种对象。每次只报告实际执行范围，合理例外与未确认项单独记录。

## 核对工具行为

- 引脚、导线、标签和装饰线使用正确的对象类型，图形上接近不作为电气连接证据。
- 连接锚点与网格适配当前工具和符号库；不将一个软件的网格数值强加给另一软件。
- 网络名的作用域、标签移动行为、同名合并规则和跨页语义按项目版本核对。
- 修改后用网络属性、高亮、连接表及适用的规则检查确认，不能只看标签位置和结点外观。
- 一手文档说明具体软件行为；本技能的左到右主通路、轻量分区、间距和标题比例是可读性约定，不冒充外部强制标准。

## 一手文档

以下说明基于 2026-11-21 核对的文档；实际使用以项目版本和当前官方说明为准。

1. [KiCad 9.0 Schematic Editor](https://docs.kicad.org/9.0/en/eeschema/eeschema.html)：参见 Electrical Connections、Grids and snapping、Electrical connections between sheets、Electrical rules checking。连接依赖有效端点；不同标签有相应作用域；标准库给出 50 mil 网格建议；ERC 能力受符号脚类型定义影响。
2. [EasyEDA Standard — Wiring Tools](https://docs.easyeda.com/en/Schematic/Wiring-Tools/)：分别定义电气连线、标签、网络标识、端口与未连接标志；电气对象与图形工具应区分。
3. [EasyEDA Pro — Net Label](https://prodocs.easyeda.com/en/schematic/place-net-label/)：网络名由导线属性表达，标签移动行为与设置有关；重排后应核对真实网络属性。

## 通用 SVG 的检查含义

生成图例时记录导线端点、器件引脚、标签锚点与预期节点。验证阶段把图形中的连接关系与记录比较，同时检查预期相连和预期分离的节点。记录本身不能代替几何核对。

人工查看实际渲染，检查文字、符号、分支结点、接口顺序、模块疏密和回路层次。检查方法见 [SVG 图例索引](svg-examples.md)。未实际运行的几何检查和未实际查看的图面检查，分别标记为“未执行”。
