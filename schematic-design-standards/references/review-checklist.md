# 交付前检查清单

使用“通过 / 失败 / 待确认 / 未执行 / 不适用”记录状态。依据真实执行证据填写，不把清单本身视为完成验证。

## A. 输入与修改范围

- [ ] 已明确是新设计、只重排、截图重绘还是仅审阅。
- [ ] 已识别工具/工程格式与目标阅读方式；已有工程未被无必要迁移。
- [ ] 已记录模糊引脚、未知值、隐藏连接和装配假设。
- [ ] 仅重排保留原电气属性；需要电气修正的事项已明确列出，没有偷偷改动。

## B. 电气连接与工程属性

- [ ] 位号在正确的整项目/层次范围内唯一；多单元与多实例关系正确。
- [ ] 引脚身份、脚号、型号/封装映射及极性无未授权变化。
- [ ] 导线端点、引脚与有效标签锚点真正连接；图形线和电气线没有混用。
- [ ] 分支、交叉、重叠线段和四向交点无歧义。
- [ ] 显式网络名、作用域、供电域及参考地与意图一致。
- [ ] 通道专用网络不会因同名误连；真实共享网络不会被错误拆开。
- [ ] 分压、RC、反馈、保护和驱动支路接在正确节点，而不仅仅“靠近正确器件”。
- [ ] 未连接标志、厂商 NC、DNP 和未知项已区分，未为了清除警告伪造状态。
- [ ] 条件允许时实际运行 ERC；每项错误/警告已分析，必要例外记录原因。
- [ ] 只重排已比较前后引脚连通分组、显式网络身份与关键属性。
- [ ] 提供 PCB 时已执行适用的一致性检查；无笼统忽略网表差异的处理。

## C. 功能组织与页面

- [ ] 每个模块的用途、输入/输出、供电及参考关系可识别。
- [ ] 主通路和反馈/辅助支路可顺线追踪；默认朝向一致，例外有清楚理由。
- [ ] 主通路有基线，辅助支路有层次，同职责元件对应对齐；不存在无理由的随机高低排列。
- [ ] 分压、RC、LDO、驱动和反馈等局部小系统紧凑。
- [ ] 组间留白和标题足以分区，模块面积按真实复杂度分配，不强制填满或等分卡片。
- [ ] 分区线不穿过电路，导线不与框线叠放，无过粗边框或装饰压过主体。
- [ ] 长回绕线已适当缩短或用合法标签替代，关键局部关系没有过度标签化。
- [ ] 完整信号链按功能级顺序展开，反馈、偏置和基准保持所属关系。
- [ ] 大 IC 分单元后仍有完整的物理器件及供电脚归属，去耦组归属明确，接口有序扇出。
- [ ] 复杂页必要时已拆页，跨页端口和来源/去向可定位。
- [ ] 重复通道几何一致，有通道身份，并显示真实差异。
- [ ] 可选、互斥和同时装配方案表达清楚。

## D. 符号与文字

- [ ] 位号、参数、脚号/脚名各有明确归属，B/C/E、G/D/S 等标注紧靠对应引脚。
- [ ] 型号、标签与注释不重叠、不压线、不遮结点或引脚。
- [ ] 器件布局已预留文字空间；公式、约束和注释引线位于独立、明确的区域。
- [ ] 标题、器件文字、普通注释和关键约束层级稳定。
- [ ] 网络名和电源名一致，单位、大小写、有效电平表达无歧义。
- [ ] 黑白阅读不损失连接、通道或状态含义。
- [ ] 无无用的解释文字或自动堆叠的测试点；真实测试点未因美观被删除。

## E. 必须实际查看的三种尺度

| 视图 | 检查重点 | 不通过时的处理 |
|---|---|---|
| 全页适配 | 模块顺序、页面密度、重复通道、标题与边框层级 | 重排模块、调整页面或拆页 |
| 目标阅读/打印尺寸 | 字号、位号、数值、脚号、注释可读性 | 增大电路/文字或重新分页，不能只让用户放大 |
| 关键局部放大 | 接点、极性、保护节点、反馈端、文字压线、近似未接 | 修复图面并重新检查受影响网络 |

有原生工程时检查实际导出的 SVG/PDF/预览；只有图片时检查实际图片；没有渲染条件就报告“图面渲染检查未执行”。

## F. 通用 SVG 图例检查

生成或更新图例时执行，普通工程审阅无须无条件重新生成全部图例。详见 [图例索引与检查方法](svg-examples.md)。

- [ ] 14 类典型画法与独立 SVG 路径对应，引用完整。
- [ ] 图例是自建通用拓扑，数字器件使用逻辑脚名，未虚构真实料号或封装脚号。
- [ ] 已记录端点、器件引脚、网络标签及预期节点。
- [ ] 几何连通检查实际执行，比较了图形路径与预期节点，未只检查元数据。
- [ ] 应相连的节点真实相连，应隔离的网络没有误并。
- [ ] 实际渲染并按三种尺度人工查看，发现的问题已修复并复查。
- [ ] 几何检查与人工检查分别记录；未运行的项写“未执行”。
- [ ] 未把 SVG 检查称为原生 ERC、实际器件性能验证或可直接生产的证明。

## G. 定稿判定

- **可交付工程定稿**：用户要求范围内，未留下实际连接错误；可执行的必需检查完成；合理例外有记录，剩余限制明确。
- **可交付草案/教学示意**：只有图像、未知引脚或未完成工程验证时，完成可做的布局工作并明确标注；不能宣称可直接生产。
- **只给评审结论**：若任务是审阅，不为满足流程额外修改工程或创建成套文件。
- 不把 ERC 零错误写成“整机完全验证”。器件额定值、环路、保护和 PCB 物理约束有独立验证范围。

## 简洁报告模板

按实际情况选用，不强制每次输出整张清单。

| 检查范围 | 状态 | 证据/未完成原因 |
|---|---|---|
| 布局与文字 | 按实际填写 | 已查看的输出及尺度 |
| 连接保持 | 按实际填写 | 原生网络比较 / 仅截图人工核对 |
| ERC | 按实际填写 | 原生工具、真实结果及例外；通用 SVG 为不适用 |
| SVG 几何连通 | 按实际填写 | 图例检查的真实结果；不替代人工图面查看 |
| 原理图—PCB 一致性 | 按实际填写 | 已执行范围，或未提供 PCB |
| 待确认项 | 按实际填写 | 具体网络、脚号、数值或装配条件 |

只报告存在的风险和检查限制，不附加与任务无关的免责声明。
