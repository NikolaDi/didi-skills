# 嘉立创 EDA 专业版操作

设计依据统一取自同级 [hardware-design](../hardware-design/SKILL.md) 和用户对当前任务最新确认的要求。需要开始原理图设计或电气改版时，先按其「原理图开画前先确认方案」处理；已确认的方案直接用于当前工程。单纯连接、只读检查、导出或打包可直接进入相应操作。

| 当前任务 | 操作入口 |
|---|---|
| 首次连接、多个窗口、断线或超时 | 按[连接与执行](references/connection.md)发现桥接、识别窗口并核对工程和活动文档。 |
| 搜索库器件、放置符号、绘制导线和标签 | 按[原理图操作](references/operations.md#原理图)读回实际引脚和网络。 |
| 导入 PCB、摆件、画板框、走线、铺铜 | 按[PCB 操作](references/operations.md#导入-pcb-与编辑板图)切换到目标板，执行已确定的布局及路径。 |
| 核对网表、运行 ERC 或 DRC、保存和导出 | 按[检查与导出](references/operations.md#检查与导出)读取本轮结果与实际交付文件。 |
| 查参数、单位、枚举和返回类型 | 查[API 速查](references/api-usage.md)，匹配实际客户端版本。 |
| 生成可分发的技能包 | 按[打包说明](README.md#打包)生成并校验本 skill 的归档。 |

优先使用公开 API。需要界面操作时，按当前窗口状态定位命令。写入前核对本次会话的窗口、工程及文档；操作中断后先读回实际状态，再继续未完成的部分。
