# 板级硬件设计

先确定本次要做的决定、板卡版本、装配版本和验收依据。只读评审以当前工程为准，交代比较基线；工程中的手改版和上次导出件可能不同。只要求列差异时，按「可读性改进、电气或装配变化、待确认项」给出具体位号和网络。

## 按任务取用

| 当前任务 | 阅读内容 | 应能回答的问题 |
|---|---|---|
| 新设计、改供电、选型、分配接口 | [需求与架构](references/architecture.md) | 最差工况是什么，哪个器件或接口限制整机？ |
| 绘制、重排、审图或对照手改版 | [原理图与连通性](references/schematic.md) | 能否沿线解释局部回路，哪些引脚或器件属性发生了变化？ |
| 封装、结构、布局、走线或投板前检查 | [PCB 与装配](references/pcb.md) | 电流如何返回，是否装得下、焊得到、测得到？ |
| 整理制板、采购、贴装与测试资料 | [生产资料与放行](references/production.md) | 工厂拿到这一版，能否唯一确定怎么做板、装什么和怎么验？ |
| 首板上电、试产、量产维护、替代料或退市 | [验证与变更](references/verification.md) | 哪些指标已测，哪个批次受影响，变更后需要重验什么？ |
| 电池供电、受控负载、模组接口或物料不一致 | [温湿度记录器复盘](references/recorder-review.md) | 如何从一个具体改动判断图面、电气与生产影响？ |

## 规则发生冲突时

| 情况 | 采用的口径 |
|---|---|
| 可读性、结构要求与器件电气条件互相制约 | 先落实实际型号的数据手册、可制造工艺和已确认的产品约束。若它们不能同时满足，指出冲突涉及的器件、工况及可选改法，让需要做取舍的人决定。 |
| 指定图幅、单页、共边框与模块自由分区 | 优先遵循项目约定；未指定时按信号流和模块复杂度分配空间。标题与留白足够时可省框，共边框属于可选版式。 |
| 「上电源下地」与侧向引脚短接 | 电源域使用有电气意义的专用符号，优先上电源下地。密集引脚可短折线引出或旋转符号，文字水平，实际网络身份可查。 |
| 「标签贴线」与「文字不压线」 | 标签靠近所属导线并有明确锚点；按目标打印尺寸检查，导线不穿过可见字形、脚号或结点。 |
| 「先定板框」与「先摆件」 | 结构已定时先锁定尺寸、安装孔和接口基准；自由板形可用初步布局估算外形，再复核装配空间与成本。 |
| 手工布线、自动辅助与外观整齐 | 遵循项目明确的布线方式。对最终铜形、关键回流、分支、间距和实际填铜做同样的检查；器件对齐须服从电气和装配要求。 |
| 未指定料号与用户委托选型 | 已获委托时依据需求和一手资料选型，写出关键取舍。缺失条件会改变耐压、电平、接口或安全方案时，指出缺口并给出可行边界。 |

## 给出结论

标明结论来自网表、器件资料、制造文件、计算还是实测。ERC 检查连接规则，DRC 检查已配置的物理规则，样机数据对应具体工况。交付说明列出实际修改、检查对象与结果、剩余问题；只完成一个阶段时，按该阶段交付。
