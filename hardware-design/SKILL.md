# 板级硬件设计

先明确本次任务的设计阶段、板卡版本、装配版本和验收依据。具体产品的器件选择、限值、装配组合及变更记录随项目维护。

## 原理图开画前先确认方案

新设计先向用户说明主要芯片的型号、封装与职责，功能拓扑、电源拓扑和重点信号。型号或封装缺失时先询问，可附候选及取舍。按[方案说明要点](references/architecture.md)补齐方案，等用户明确确认这一版后，再放置器件和连线。已有工程的电气改版只说明并确认受影响的部分；用户已明确确认同一方案时直接执行。只读审图或纯图面整理按原范围进行。

## 规则发生冲突时

| 情况 | 采用的口径 |
|---|---|
| 可读性、结构要求与器件电气条件互相制约 | 先落实实际型号的数据手册、可制造工艺和已确认的产品约束。若它们不能同时满足，指出冲突涉及的器件、工况及可选改法，让需要做取舍的人决定。 |
| 图幅与分框 | 简单原理图默认单页 A4，独立模块共边分框。复杂设计按交付介质与电路复杂度选择图幅和分页。 |
| 电源与地 | 使用专用符号。简单侧向连接优先旋转符号，沿引脚短接；其余连接尽量上电源、下地。 |
| 普通信号标识 | 同页普通信号统一用网络标签，局部回路优先实线连接；跨页与层次接口按作用域使用端口。 |
| 标签与导线 | 锚点接在所属网络上，可见字形与导线之间留净距，以目标打印尺寸检查。 |
| 板框与布局 | 先落实已有机械边界。自由板形可先定初步外形，再与布局迭代。 |
| PCB 布线 | 所有网络逐网手工决定路径，包括层、拐点和过孔位置。 |

## 给出结论

标明结论来自网表、器件资料、制造文件、计算还是实测。ERC 检查连接规则，DRC 检查已配置的物理规则，样机数据对应具体工况。交付说明列出实际修改、检查对象与结果、剩余问题；只完成一个阶段时，按该阶段交付。
