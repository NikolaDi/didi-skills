# 原理图表达与连通性复核

## 从读者需要追踪的回路开始

先放接口、供电入口和关键芯片，再放外围器件。模块沿能量或信号流排列，默认左入右出、上电源下地。按实际复杂度分区；密集大芯片可以按功能拆单元，各单元保留同一物理位号和电源域。重复通道先做好一个，再复用相对位置并逐路确认真实差别。

| 局部电路 | 推荐画法 | 审阅时沿线回答 |
|---|---|---|
| 稳压、升压与反馈 | 输入/输出电容接各自电源节点，电感、整流器、开关节点构成可追踪的功率通路；反馈上下臂串排，中点实线接 FB | 反馈取自哪一侧？切断受控支路后，供电与反馈是否仍有效？ |
| 高边开关与下拉驱动 | 开关管靠电源路径，栅源偏置就近画，驱动管和控制信号靠栅极。相同职责的两路画成相同方向 | 复位时默认通还是断？体二极管朝哪侧？两路错装是否会改变状态？ |
| 复位、采样、上拉 | 上拉在上、下拉或电容在下，节点实线接目标脚；一对总线上拉并排 | 采样中点在哪里？掉电时节点受哪个域驱动？ |
| 报警或感性负载 | 负载、开关、偏置与适用的钳位元件放在一起 | 导通时电流经哪条路返回？关断瞬间电流走哪里？ |
| 通信、天线和装配变体 | 标明连接对象、方向和电压域；选择点旁注明装配条件 | 断电的一侧会否受驱动？另一装配版本中还剩哪些支路？ |

优先用实线画完整局部关系。跨模块使用网络标签，跨页或层次接口按真实作用域选择端口。采用电源和地的电气符号，区分常供电、受控、模拟参考等不同网络。开关节点、反馈和使能按其信号身份表示。分支用明确结点，错开易误读的四向交叉。框线独立于电气导线。

位号、值、引脚功能和必要脚号贴近对象，朝向调整后仍能辨认 B/C/E、G/D/S、极性和 1 脚。说明性文字用于表达关键时序、电压范围、互斥贴装或外部接口定义。旋转和镜像之后按实际脚号再查一次。

## 证明调整保留了什么

1. 取对了工程、图页以及修改前后版本。按「实例路径、位号、脚号」建立每个网络的成员集合，同时保留显式网名及作用域；自动生成的内部网名允许变化。
2. 比较连接分组，以及器件增减、极性、值、封装、订货号、DNP 状态、接口定义和注释。仅重排时把意外差异列为问题；设计改版时逐项对应授权改动。区分厂商 NC、显式未连接、未知连接和不装器件。
3. 运行适用的原生 ERC，记录每项错误、警告及有依据的例外。依据网表复核关键网络和跨页连接。提供 PCB 时进一步比对位号、脚号到焊盘网络。仅有截图时标明可见连接与推断边界。
4. 实际渲染全页看模块顺序，以目标打印尺寸看字体，再放大检查密集引脚、结点、交叉和极性。黑白打印仍应可辨。修正图面后复核受影响的引脚。详见[改图实例](recorder-review.md)。
