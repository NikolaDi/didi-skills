# 原理图表达与连通性复核

## 从读者需要追踪的回路开始

绘制具体电路时，按拓扑查阅[典型电路画法与验收重点](circuit-patterns.md)。每类都有独立图例，可对照检查端子、节点和支路。

用户确认[设计方案](architecture.md)后，先放接口、供电入口和关键芯片，再放外围器件。简单原理图默认单页 A4，独立模块共边分框，公共边只画一次。复杂设计按交付介质与电路复杂度确定图幅和分页，使局部回路在目标尺寸下仍可顺线阅读。

模块沿能量或信号流排列，默认左入右出。简单的侧向供电或接地优先旋转专用符号，沿引脚短直线连接，文字保持水平。其余位置尽量上电源、下地。密集大芯片可以按功能拆单元，各单元保留同一物理位号和电源域。重复通道先做好一个，再复用相对位置并逐路确认真实差别。

| 局部电路 | 推荐画法 | 审阅时沿线回答 |
|---|---|---|
| 稳压与反馈 | 沿功率路径排列元件，明确输入、输出和取样节点。使用反馈分压时，上下臂串排，中点实线接反馈脚 | 调节的电压取自哪里？哪些压降包含在反馈回路内？ |
| 负载开关与驱动 | 开关元件置于负载电流路径上，偏置和驱动接在实际控制节点旁 | 控制端未驱动时处于什么状态？关断后是否仍有电流路径？ |
| 复位、采样、上拉 | 上拉在上、下拉或电容在下，节点实线接目标脚；同一接口的偏置元件就近成组 | 采样中点在哪里？掉电时节点受哪个域驱动？ |
| 负载与瞬态保护 | 负载、开关、偏置与适用的钳位元件放在一起 | 导通时电流经哪条路返回？关断瞬间电流走哪里？ |
| 外部接口与装配变体 | 标明连接对象、方向和电压域；选择点旁注明装配条件 | 断电的一侧会否受驱动？另一装配版本中还剩哪些支路？ |

优先用实线画完整局部关系。同页普通信号需要标识时统一使用网络标签；跨页或层次接口按真实作用域选择端口。标签锚点准确接入所属导线，文字可贴近，目标打印尺寸下字形与导线之间须看得见空隙。采用电源和地的电气符号，区分常供电、受控、模拟参考等不同网络。开关节点、反馈和使能按其信号身份表示。分支用明确结点，错开易误读的四向交叉。框线独立于电气导线。

位号、值、引脚功能和必要脚号贴近对象，朝向调整后仍能辨认 B/C/E、G/D/S、极性和 1 脚。说明性文字用于表达关键时序、电压范围、互斥贴装或外部接口定义。旋转和镜像之后按实际脚号再查一次。

## 器件参数标注

位号单列，旁边用一行显示参数或型号。同类器件位置和单位写法一致，数值紧跟单位，多项用 `/` 分隔，整串不加空格。以下数值仅示范写法。

| 器件 | 图面标注 | 示例 |
|---|---|---|
| 电阻 | 必标阻值。精度或功率有设计要求时才追加，顺序为阻值、精度、功率 | `10KΩ`、`10KΩ/0,1%`、`0.2mΩ/1W` |
| 电容 | 容量/额定耐压。有极性电容用符号标清正负，介质和材质留在 BOM | `100nF/16V`、`22uF/10V` |
| 小信号电感 | 感值 | `10nH` |
| 功率电感 | 感值/饱和电流。第二项固定对应数据手册的 Isat | `4.7uH/3A` |
| 磁珠 | 阻抗及测试频率。电源支路有电流要求时追加额定电流 | `600Ω@100MHz`、`600Ω@100MHz/1A` |
| 无源晶体、有源振荡器 | 只标频率 | `32.768kHz`、`24MHz` |

其他器件在位号旁默认只标设计型号，保留用于区分功能的后缀。完整选型要求随[工程 BOM](bom-and-costing.md)维护。

## 证明调整保留了什么

### 连线与网络身份

- 新画或重排前，先从现有网表或设计依据列清模块的输入、输出、供电、参考地和装配差异。将关键引脚对应到预期网络，同时列出应当隔离的节点。简单电路可直接在评审记录中完成。
- 引脚端点、导线端点和标签锚点采用与符号库兼容的电气网格。多线汇合处从任一引脚查实际网络成员，分别核对该接入的支路和仅穿越的线。说明箭头和注释引线用图形对象。整理已有符号时移动原对象，避免在同一位置留下第二个符号或标签。
- 一个节点使用一个规范网名；旧名用于追溯时写在注释中。主动低电平信号采用项目统一的标记，同类接口按实例和功能命名。差分对的正负端成对扇出，保持顺序；总线逐成员核对名称及端点。电源、开漏、双向和被动等引脚属性按真实功能定义。
- 多页工程在图签给出页名、版次和页码，需要跨页追踪的接口标清来源、去向、方向和电源域。复用子页时选择两个实际实例，验证各自的专用节点彼此隔离，共享节点连至预期上级网络。多单元器件核对整板物理位号、单元归属和全部电源脚。

### 图面与实物的对应

多级电路把主通路放在连续的阅读轴上，让偏置、配置、反馈支路紧邻所属级。先给脚号、数值和出线留位置，再通过调整器件位置或朝向减少交叉、折返与重复线段。模块标题写功能，图签区预留净空。负电源和浮动参考端按真实电位标识。

图面距离表达功能归属。若去耦需要靠近特定供电脚或反馈必须从指定位置取样，应明确关联的引脚或取样点，并在 PCB 上复核。对外接线图标清板端或线端、插合面或焊接面，再按物理脚号查对。保留真实测试点器件与位号，新增测试点按实际测量需求决定。

检查电源符号时确认引脚到符号的短引线清楚，符号名称靠近对应符号，在密集区用完整字形判断归属。

### 按证据复核

1. 取对了工程、图页以及修改前后版本。按「实例路径、位号、脚号」建立每个网络的成员集合，同时保留显式网名及作用域；自动生成的内部网名允许变化。
2. 比较连接分组，区分厂商 NC、显式未连接、未知连接和不装器件。仅重排时逐项解释意外差异；涉及器件、电气功能或装配的修改按[设计变更复核](design-change-review.md)追踪。
3. 运行适用的原生 ERC，记录每项错误、警告及有依据的例外。依据网表复核关键网络和跨页连接。提供 PCB 时进一步比对位号、脚号到焊盘网络。仅有截图时标明可见连接与推断边界。
4. 实际渲染全页看模块顺序，以目标打印尺寸看字体，再放大检查密集引脚、结点、交叉和极性。黑白打印仍应可辨。修正图面后复核受影响的引脚。

从图片重绘时，将模糊端子和遮挡连接标为待确认，并指出需要原图、工程数据还是器件资料。绘制通用矢量图例时，分别检查实际图形路径与预期节点的连通关系、渲染后的可读性。工程 ERC 结果取自可编辑电气工程。
