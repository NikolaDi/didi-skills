# 生产资料整理与放行

按「裸板、装配、测试」确定接收人，从委托和工程中识别板号、硬件版、装配变体及单板/拼板形式。数量影响总备料或拼板时再核实数量。用一个已确认的设计版本生成相关文件。在实际生产目录中附交付清单，写明文件名、版本、用途、工艺条件和例外；组织方式以项目或制造方约定为准。

| 接收方 | 典型资料 | 放行时的关键核对 |
|---|---|---|
| 裸板厂 | 铜层、阻焊、丝印、外形、槽和钻孔数据，制板说明及叠层；按约定补阻抗表、拼板图或电测网表 | 板号、层数与层序、外形尺寸、孔槽和孔属性、单位和原点一致。铜厚、成品板厚、表面处理和特殊工艺在文件与订单中一致。Gerber 的图层及作业文件语义见[格式维护方说明](https://www.ucamco.com/en/gerber)。 |
| 采购与备料 | 按装配版本分配的 BOM，包括位号集合、单板数量、值与规格、封装、制造商、完整订货号、批准替代料及 DNP | 每行实装位号数量等于单板数量。核对工程值、显示值与订货号，尤其是从别处复制的阻容及极性件。把互斥选装写成每个版本的明确装料表。 |
| 贴片与后焊 | 实装位号的贴装坐标（中心、单位、原点、顶底面、旋转）、装配图、极性与 1 脚、后焊说明、需要的锡膏层或钢网要求 | 坐标与装配图使用同一单板或拼板基准。选取非对称 IC、二极管、连接器和底面件叠图核对；确认对方的旋转和底面观察约定。 |
| 烧录与测试 | 工位接线、夹具版本、固件标识、配置、步骤、测试点、工况、判据与记录字段 | 首件可依资料完成烧录和判定。约定板号、序列号、硬件/固件版本、测量值和返修记录如何关联。 |

## 三个能发现真实错误的检查

1. **重新打开将要交付的文件。** 交付裸板资料时，在独立查看器叠合层图、外形和钻孔，用已知尺寸和非对称基准核对比例、原点与顶底面。检查镀孔/非镀孔、槽、开窗和板边实际输出。交付贴片资料时，以该板版次的装配图或板图核对坐标、面别、方向及适用的钢网资料。
2. **先查重复，再以位号对账。** 在选定变体中展开 BOM 位号，按单板位号检查重复和冲突，拼板坐标按「板实例＋位号」检查。每个机贴器件应有一条适用坐标，检查同一位号是否在顶底面重复出现。然后比较 BOM 实装与坐标位号的差集，把后焊、预装模组等差异对应到具体工序。检查未装件未进入贴装工位、选装组满足该变体的装配数量，并在装配图上能定位。保留 DNP 焊盘是常见设计选择，其生产处理取决于本版装配与钢网要求。
3. **确认工厂收到的是同一版本。** 从交付清单回查可编辑工程、受控库、板版次和变体。制板文件、BOM、坐标、装配图与测试固件使用相容的版本。归档实际发放的资料、已接受的工艺问答和首件结果。后续变更列出替换文件与受影响批次，保留原批次的可追溯资料。

发现料号/值不一致、极性或坐标歧义、变体相互矛盾时，点明受影响的位号和文件，将相应工序列为待确认。整理资料、工程放行和实际向工厂发单是独立动作，按本次委托范围执行。
