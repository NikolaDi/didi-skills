# 嘉立创 EDA 专业版操作

从 [hardware-design](../../SKILL.md) 进入本流程后，按实际任务读取相应步骤。连接、只读检查和导出可以直接进入对应操作。

| 当前任务 | 操作入口 |
|---|---|
| 首次连接、多个窗口、断线或超时 | 按[连接与执行](connection.md)发现桥接、识别窗口并核对工程和活动文档。 |
| 搜索库器件、放置符号、绘制导线和标签 | 按[原理图操作](operations.md#原理图)读回实际引脚和网络。 |
| 导入 PCB、摆件、画板框、走线、铺铜 | 按[PCB 操作](operations.md#导入-pcb-与编辑板图)切换到目标板，执行已确定的布局及路径。 |
| 从当前原理图导出 BOM | 按[读取 BOM 源数据](operations.md#读取-bom-源数据)取得各实例的有效属性及图面标注，再进入通用 BOM 流程。 |
| 核对网表、运行 ERC 或 DRC、保存和导出 | 按[检查与导出](operations.md#检查与导出)读取本轮结果与实际交付文件。 |
| 查参数、单位、枚举和返回类型 | 查[API 速查](api-usage.md)，匹配实际客户端版本。 |

优先使用公开 API。需要界面操作时，按当前窗口状态定位命令。写入前核对本次会话的窗口、工程及文档；操作中断后先读回实际状态，再继续未完成的部分。
