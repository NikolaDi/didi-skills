# circuit-to-notebook-export 导出包

此包用于备份/迁移 `circuit-to-notebook-export` 技能规则。

包含：
- `SKILL.md`：主技能说明
- `references/layout-rules.md`：通用原理图布局规则
- `references/symbol-library.md`：标准器件符号与引脚规则
- `references/data-schema.md`：机器可读电路数据约定
- `assets/model-usage-template.md`：后续模型使用说明模板

当前版本根据 2026-10-23 会话中确认的布局要求整理。
