## 阅读与修改

读取本方案时：
1. 优先读取 `-电路数据.json` 获取连接关系。
2. 使用 `-原理图.svg` 理解布局、功能分组和阅读方向。
3. 使用 `-方案笔记.html` 获取方案原理、公式、参数影响和复用说明。
4. 不从 SVG 几何位置推断不存在于 JSON 的电气连接。
5. 若 JSON 与图面冲突，报告冲突，不自行猜测。
6. 修改参数时，说明哪些公式、工作范围、滤波、稳定性和保护阈值需要重算。
7. 修改布局时，可以调整位置、方向、连线与网络标签，但不得改变真实网络成员、极性和引脚角色。
