# 通用原理图布局规则

## 1. 硬约束
1. 保持真实逐脚连接、极性、元件参数和串并联关系。
2. 不合并不同参考网络：系统地、浮动参考、隔离地等必须区分。
3. 旋转/镜像不得改变 B/C/E、G/D/S、A/K、运放 +/- 等真实角色。
4. 导线必须落到标准符号的真实端点。
5. 输入、输出、控制、供电、参考、双向接口必须从当前电路视角明确标识。
6. 保护器件的实际保护节点和泄放参考不得改变。

## 2. 阅读方向
1. 常规信号优先左进右出。
2. 垂直方向优先高电位在上、低电位在下；只在同一工作域内应用。
3. 控制信号、采样信号优先水平。
4. 已选择为竖向的主电流通路，串联器件尽量同轴竖排，不突然横置。

## 3. 放大器/比较器/模拟前端
1. 先按主器件实际输入脚确定输入网络位置，再放电阻和反馈元件。
2. 输入串联电阻、采样节点优先与对应输入脚处于自然的同一水平区域，不要求机械地逐端同高。
3. 同相/反相/差分/跨阻网络按真实拓扑画，不套固定模板。
4. 反馈元件靠近实际反馈节点，回路短、连续、易追踪。
5. 接参考电位的支路可向下或水平放置，以减少折线和提高可读性为准。
6. 分压下臂通常位于分压节点下方；若水平布局更清晰，可以水平放置但必须明确参考端。

## 4. 输入、输出与保护
1. 输入保护：外部输入端口 → 已有保护/滤波 → 内部功能。
2. 输出保护：内部输出 → 已有滤波/保护 → 外部输出端口。
3. 保护器件靠近所保护接口，不跨越不该跨越的串联元件。
4. 同节点的输出电阻与滤波电容紧凑相邻。
5. 双轨钳位：被保护信号线作为中心，上钳位器件在上、下钳位器件在下，公共点直接落在信号线上；上端接高参考轨、下端接低参考轨/GND。
6. BAV99 等集成双二极管若实际拓扑为双轨钳位，绘图时可拆成上下两个二极管形态，但必须表示为同一个物理封装并保留真实公共脚。

## 5. 稳压器、基准和小系统
1. 三端稳压器/基准及其设定、分压、反馈、稳定元件视为一个局部小系统。
2. 小系统内部器件尽量紧凑，优先先完成局部关系，再接主图。
3. 引脚角色如 IN/OUT/GND/ADJ、K/A/REF 应贴近实际器件端子。

## 6. 晶体管、MOS、二极管等引脚标识
1. B/C/E、G/D/S、A/K、K/A/REF 等功能名放在器件引脚附近，而非长导线远端。
2. 如果同时显示封装脚号，使用类似 `1 · B`、`2 · E` 的方式区分脚号与角色。
3. 文字不能遮挡极性箭头或器件符号。

## 7. 紧凑与留白
1. 反馈、偏置、补偿靠近主器件。
2. 同节点阻容、滤波与保护形成局部紧凑组。
3. 组内间距小，组间用适当留白表达功能边界。
4. 避免无用途的大空白和长导线。
5. 不为了“严格对齐”牺牲整体美观和阅读顺序。

## 8. 连线与接点
1. 导线以水平/垂直为主，允许必要短折线。
2. 一般优先 T 形接点；若四向接点直接表达同一节点更清楚，可以保留，但必须有明显实心连接点且确认同网。
3. 同一电源/地网络可以使用局部同名符号减少贯穿全图的长线。

## 9. 标注
1. 位号、数值、型号放在器件附近，形成清楚的标签组。
2. 同类器件标注位置尽量一致。
3. 为长型号、原标号切换留空间。
4. 不让文字压线、穿线或靠近另一器件到难以判断归属。

## 10. 测试点
1. 学习主图默认隐藏与当前理解无关的 TP。
2. 调试、校准、测量主题需要时再显示测试点。
3. 测试点记录和网络仍保留在 JSON。

## 11. 拆图判断
1. 主信号链、反馈、偏置、补偿、输出滤波和近端保护优先同图。
2. 如果读者理解一部分时需要频繁查看另一部分，就不拆。
3. 只有关联低、接口少、独立阅读成立的模块才拆图。
