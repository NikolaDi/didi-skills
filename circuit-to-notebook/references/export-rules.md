# 导出路径与汇总规则

## 每次询问

每次导出都询问用户本次保存的根目录，并等待明确回复；不配置默认根目录，也不自动复用历史路径。即使上下文出现过路径，也要询问本次是否使用该位置。用户可选择同一根目录持续汇总，也可选择新目录单独归档。

要求绝对路径。用户给出相对路径时，先说明它对应的绝对路径并请用户确认。只有路径明确后才创建目录和写入产物；路径不可写或无法访问时，报告问题并重新询问，不改存技能目录、当前工作目录或临时目录。

## 目录结构与命名

在用户选定的根目录下，按下列约定组织，不移动或清理已有内容：

```text
<导出根目录>/
├── circuit-notebooks-index.md
└── <方案目录名>/
    ├── <方案名>-电路数据.json
    ├── <方案名>-方案笔记.html
    ├── <方案名>-原理图.svg
    ├── <方案名>-知识地图.svg
    └── <方案名>-模型使用说明.md
```

- 目录名与文件名前缀由方案标题生成，将 Windows 禁止的字符 `< > : " / \ | ? *` 和控制字符替换为 `-`，去掉末尾空格与句点；空名称或 Windows 保留名称使用 `方案-` 前缀生成有效名称。页面和 JSON 的标题保留原文。
- 首次导出使用清理后的方案名作为目录名。同名目录已存在时，新建 `<方案名>-YYYYMMDD-HHmmss`；仍重名则追加递增序号，不覆盖既有产物。
- 文件间引用使用同目录相对路径。HTML 应可直接打开查看；必要数据内嵌到 HTML，避免依赖 `file://` 下受限的 `fetch` 才能呈现笔记。
- 本技能不自动删除历史版本、旧目录或用户文件。清理须由用户另行授权。

## 汇总索引

5 个交付文件生成并检查通过后，再更新根目录的 `circuit-notebooks-index.md`：

- 每个方案目录一条记录，包含方案标题、导出时间、功能摘要，以及笔记 HTML、电路 JSON、原理图、知识地图和模型使用说明的相对链接。
- 保留已有记录及用户手写内容；同一个方案目录更新对应记录，新目录新增记录。不要仅凭标题相同覆盖旧记录。
- 链接按真实目录和文件名生成，对空格、`#` 等 URL 特殊字符进行编码；标题或摘要中的表格分隔符需要转义。
- 仅登记本次验证通过的产物，不扫描其他路径或自动汇入未经核对的文件。生成失败时不新增完成记录。

## 模型使用说明与交付

根据 `assets/model-usage-template.md` 填写本次方案的文件清单、导出时间和相对索引位置；用实际文件名替换模板占位符。说明中的链接使用相对路径，使整套笔记可以一起迁移。

完成后核对 5 个文件存在、索引链接指向真实文件，再向用户提供：

1. 本次方案笔记 HTML 的绝对路径链接，作为首要查看入口。
2. 根目录汇总索引的绝对路径链接，作为集中查看入口。
3. 本次方案目录的绝对路径链接。
